# Game Roles Assets

Folder aset lokal Game Roles. Gambar dikirim langsung sebagai media agar tetap utuh dan tidak dipotong menjadi thumbnail.

- `roles/common`: Role yang memakai gambar yang sama untuk semua lokasi.
- `roles/warga`: Variasi Warga untuk desa, kota, dan kru/luar angkasa.
- `roles/mayor`: Variasi Mayor untuk desa, kota, distrik, dan kru/luar angkasa.
- `scenes`: Gambar suasana malam, fajar, voting, eksekusi, seri, dan hasil permainan.
