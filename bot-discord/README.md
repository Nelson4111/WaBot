## Overview

**NelBot** is a feature-rich Discord bot built with `discord.js v14`, centered around high-quality music playback via **Lavalink v4 (`Kazagumo`/`Shoukaku`)**. It also includes moderation, automod, invite tracking, giveaways, user profiles, and server utilities with persistent SQLite storage.

---

## Features

- 🎵 **Music** — Play from YouTube Music, Spotify, Apple Music, Deezer, and more. Full queue controls, filters (Bassboost, 8D, Nightcore), autoplay, lyrics, liked songs, 24/7 mode, now-playing cards.
- 🛡️ **Moderation & AutoMod** — Ban, kick, mute, purge, lock/hide channels, anti-link, anti-spam, anti-mention, anti-caps, anti-NSFW.
- 📈 **Invite Tracking** — Full invite tracking, leaderboard, fake/rejoin detection, invite logs.
- 🎉 **Giveaways** — Start, end, and reroll giveaways with customizable prizes and timer.
- 👤 **User Profiles** — Bio, badges, friends, marry, rank system, profile cards.
- 🛠️ **Utility & Info** — User/server info, avatar, audit logs, timers, system stats.
- 👑 **Owner Tools** — Blacklist, no-prefix access, server list, reload, restart, backup.
