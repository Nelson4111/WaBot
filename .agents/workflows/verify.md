# Verification Workflow

Perform verification of the current implementation.

## Step 1

Inspect recent changes.

## Step 2

Identify affected functionality.

## Step 3

Determine appropriate tests.

## Step 4

Run:

- Tests
- Lint
- Type checking
- Build
- Runtime verification

where applicable.

## Step 5

Check logs for:

- Errors
- Warnings
- Unexpected behavior
- Reconnection loops
- Memory/resource problems
- Unhandled exceptions

## Step 6

Report honestly:

### Verification Summary

Status:
PASS / PARTIAL / FAIL

### Tests

List each test and result.

### Problems Found

List remaining problems.

### Confidence

Explain what has actually been verified and what has not.
