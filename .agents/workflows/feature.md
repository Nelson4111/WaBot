# Feature Development Workflow

When this workflow is invoked:

## Phase 1: Understand

Determine:

- Requested behavior
- Existing related functionality
- Expected inputs
- Expected outputs
- Constraints
- Edge cases

Inspect the existing implementation.

Do not modify code yet.

## Phase 2: Architecture

Determine:

- Where the feature belongs
- Which existing modules should be reused
- Which new modules are necessary
- Whether dependencies are required

Avoid unnecessary architectural changes.

## Phase 3: Plan

Create an implementation plan containing:

1. Files to create
2. Files to modify
3. Changes per file
4. Data flow
5. Error handling
6. Testing strategy
7. Risks

Request approval before implementation.

## Phase 4: Implement

Implement the approved plan.

Keep changes focused.

## Phase 5: Verify

Verify:

- Feature behavior
- Error handling
- Existing functionality
- Startup
- Relevant tests
- Runtime behavior

## Phase 6: Report

Summarize:

Feature:
Implementation:
Files changed:
Tests:
Results:
Known limitations:
